## 练习题

### 练习题 8.1

考虑三个具有下述起始时间和结束时间的进程：

|进程|起始时间|结束时间|
|-|-|-|
|A|0|2|
|B|1|4|
|C|3|5|

对于每对进程，指出它们是否是并发地运行的：

|进程对|并发的？|
|-|-|
|AB||
|AC||
|BC||

答：

|进程对|并发的？|
|-|-|
|AB|是|
|AC|否|
|BC|是|

### 练习题 8.2

考虑下面的程序：

```c
/* code/ecf/forkprob0.c */
#include "csapp.h"

int main()
{
    int x = 1;

    if (Fork() == 0)
        printf("printf1: x=%d\n", ++x);
    printf("printf2: x=%d\n", --x);
    exit(0);
}
/* code/ecf/forkprob0.c */
```

* A. 子进程的输出是什么？
* B. 父进程的输出是什么？

答：

* A. 2
* B. 0
